# gowebfilter-website

Source of the [gowebfilter](https://github.com/Yjlion/gowebfilter) project site, a Jekyll site using the
[Just the Docs](https://just-the-docs.com) theme and deployed to GitHub Pages by
`.github/workflows/jekyll-gh-pages.yml`.

## Local preview

```bash
bundle install
bundle exec jekyll serve
# http://127.0.0.1:4000/gowebfilter-website/
```

## Deploying

In the repo's **Settings → Pages**, set **Source** to **GitHub Actions**. Pushes to `main` then deploy.
